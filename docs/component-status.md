## Intentional deviations from shadcn

Behavior or API that differs from the shadcn source, and why. Everything else is shadcn's.

| Component | Deviation | Reason |
| --- | --- | --- |
| Select | `SelectContent` defaults `position="popper"`, `align="start"`, `sideOffset={4}` (shadcn: item-aligned, center) | Figma draws the list under the trigger |
| Select, Input, Textarea | `label` / `hint` / `marker` render the Field anatomy | API Contract: built-in field anatomy |
| Button | `variant` default·outline·ghost + `intent` + `shape` + `loading` (shadcn: variant incl. destructive / secondary / link) | API Contract names |
| Badge | `variant` default·outline·subtle + `intent` + `size` | API Contract names, Figma variants |
| Dropdown Menu | item `intent="destructive"` (shadcn `variant`); checkbox items show a small switch at the end, radio items a check at the end | API Contract name (pending confirmation); Figma item types |
| Checkbox | indeterminate shows a minus icon | Figma draws it; shadcn has no indeterminate icon |
| Popover | content gets aria-labelledby / -describedby from PopoverTitle / PopoverDescription | Radix role=dialog has no accessible name (axe) |
| Dialog, Sheet | close positioned into the header bar (still rendered last); `DialogBody` / `SheetBody` slot, focusable only while it scrolls | Figma shell layout; axe scrollable-region-focusable |
| Slider | the Slider's `aria-label` / `aria-labelledby` are forwarded to every thumb | Radix puts role=slider on the thumbs without a name (axe) |
| Toast | `theme` prop instead of next-themes | next-themes is not an approved dependency |
| Command | `CommandEmpty` goes after `CommandList` in our stories (shadcn puts it inside) | Inside, it sits in role=listbox, which may only contain options (axe aria-required-children) |
| Combobox | shadcn ships Combobox as an example, not a component; Anvil exports `Combobox`, `ComboboxTrigger`, `ComboboxContent`, `ComboboxItem`. The popover is `aria-labelledby` its trigger | One trigger / list look across products (API Contract: Combobox = Popover + Command); Radix Popover's role=dialog otherwise has no name (axe aria-dialog-name) |
| Command | `CommandSeparator` is a `role="none"` div using cmdk's `useCommandState` (same hide-while-searching behavior) instead of cmdk's Separator | cmdk hard-codes `role="separator"`, which a `role="listbox"` may not contain (axe aria-required-children) |
| Command · Dropdown Menu | Shortcut text turns `--muted-foreground` on the highlighted row | `--foreground-subtle` on `--muted` is 4.34:1 (axe color-contrast); hidden until stories stopped typing on load |
| Select · Dropdown Menu | Stories that open on load still move focus into the list (Select highlights the selected item) | Radix exposes no initial-focus hook on these contents; that is their real open behavior |
| Alert Dialog | `AlertDialogAction` / `AlertDialogCancel` take `intent` and `loading` (Button props) and default to `size="sm"`; a loading action keeps the dialog open | Figma: footer buttons are size sm; `variant` destructive is the action's intent; `loading` is Button loading (API Contract) |
| Alert Dialog | Header with `AlertDialogMedia` gets `grid-cols-[auto_1fr]` | shadcn leaves the columns implicit, so the title lands mid-width beside the media |
